# Manhwa Hub – Userscript

Userscript für den Manhwa Hub. Es verbindet Scan-Seiten wie Asura oder Thunder mit deiner Bibliothek im Hub:

- merkt sich deinen Lesestand im Kapitel und springt beim Öffnen an die letzte Stelle
- zeigt im Lesemodus nur die Kapitelbilder, ohne Werbung, Pop-ups und Kommentare
- sammelt Cover, Genres und Beschreibungen für die Bibliothek
- sucht vom Hub aus nach neuen Kapiteln
- findet Serien auf Übersichtsseiten für „Entdecken“

## Installieren

1. Firefox installieren und dort das Add-on **Tampermonkey** hinzufügen.
2. Diesen Link öffnen und in Tampermonkey auf **Installieren** tippen:
   https://raw.githubusercontent.com/de-joneh/manhwa-hub/main/manhwa-hub.user.js
3. Den Hub in Firefox öffnen.

Updates holt sich Tampermonkey automatisch. Sofort geht es im Tampermonkey-Dashboard über „Nach Updates suchen“.
